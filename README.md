# nizarhazaymeh.github.io

My engineering portfolio — live at **https://nizarhazaymeh.github.io**

A single self-contained page: no build step, no framework, no dependencies. Projects, roles,
technologies and a timeline of engagements, generated from my Git history.

## About the private work

Some of the platforms here were built for clients and organisations that own the code. Those
entries describe the work, my role and the stack, but deliberately name no repository and list no
internal modules. The public repositories link out.

## Source

The generator that produces this page is kept privately — it reads the full commit history across
every repository I contribute to and derives the project list, roles, language mix and timeline
from it.
